# CDST Website

A responsive static redesign for CDST Informatics, using the NS COMPILER page’s deep navy and gold visual direction. The page combines CDST education and support content with the software, mobile, academic project and cloud service categories requested for the redesign. No login or account portal is included.

## Run locally
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Internet connection is needed for Google Fonts and the externally hosted CDST logo.

## Included
- Nine responsive header destinations (Home, About Us, Services, Courses, Industrial Training, IEEE Projects, Faculty, Gallery and Contact), each linked to its own section in the single-page site.
- An animated horizontal image gallery above “What brings you here?” and a glowing CDST–Bosch MOU panel after the inquiry section.
- A responsive flexbox section featuring training and internships for all Diploma and B.Tech departments, plus web design, desktop application and web application services.
- Quick-start cards, CDST and technology services, training, platform feature cards, course specialties and trust sections.
- Inquiry form that opens a pre-filled email to `info@cdst.co.in` after browser validation. It does not submit to a server.
- Source-derived published page/service archive with search and detail view.
- A horizontal gallery that shuffles the seven local images in `assets/img/`, gives every image a glowing border, advances every five seconds, and excludes the Bosch partnership banner.
- Responsive card grids use staggered scroll-in animations; faculty cards highlight the supplied qualifications and a general faculty-member designation.
- `content.js` and `SOURCE_INVENTORY.json` containing source-derived content and attachment references.

## Important source limitations
The WordPress WXR export contains posts, pages, metadata and attachment references, but is not a full website backup. It does not include the theme, plugins, database state or all page-builder assets. The archive preserves readable page content where available. Local gallery and Bosch images are in `assets/img/`; Google Fonts and the CDST logo require an internet connection.

## Legacy medical content
The Spartan / medical education content is retained as requested. The exported text contains historical claims; verify current accreditation, admissions, fees, exam and graduate-outcome information with the university before republishing as current information.
